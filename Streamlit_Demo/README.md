# EEG Depression Severity Classification Demo

This folder contains a Streamlit web application for demonstrating participant-level depression severity classification using resting-state, eyes-closed EEG-derived features.

## Important Data Notice

The original EEG spreadsheets and participant-characteristics file are not included in this GitHub repository because they contain research data and participant-related information.

The required modeling dataset is excluded by `.gitignore`. Therefore, the Streamlit demo requires the authorized local copy of the processed dataset before it can be run.

The application is intended for educational, research, and AI-competition demonstration purposes only. It is not a medical device and must not be used for diagnosis or treatment decisions.

How to Run the Demo Locally
Step 1: Prepare the project
Download or clone the project repository to your computer.
Then place your authorized local copy of the processed dataset in the Streamlit_Demo folder:
text
EEG_Depression_Project/
└── Streamlit_Demo/
    ├── app.py
    ├── requirements.txt
    ├── README.md
    └── final_df.csv
The local final_df.csv file should be the processed participant-level EEG feature table generated by the EDA notebook.
Do not upload this file to a public repository.
Step 2: Install the required packages
Open PowerShell or Command Prompt from the project root and run:
powershell
& "C:\Users\<YourUser>\miniconda3\envs\ai311\python.exe" -m pip install -r .\Streamlit_Demo\requirements.txt
If Python is available directly on your system, you can instead run:
powershell
python -m pip install -r Streamlit_Demo/requirements.txt
Step 3: Start the Streamlit application
Run:
powershell
& "C:\Users\<YourUser>\miniconda3\envs\ai311\python.exe" -m streamlit run .\Streamlit_Demo\app.py
Alternatively:
powershell
python -m streamlit run Streamlit_Demo/app.py
Step 4: Open the application
After the application starts, open the local address displayed in the terminal. Usually, the address is:
text
http://localhost:8501
Keep the terminal open while using the application.
To stop the application, press:
text
Ctrl+C
Expected Prediction Classes
The application predicts one of the following three severity categories:
Minimal depression
Mild depression
Moderate depression
The prediction is generated from EEG-derived features only. BDI-II and PHQ-9 questionnaire scores are not used as model inputs.
Privacy and Responsible Use
The application is a research demonstration. Its predictions should not be interpreted as medical conclusions.
The model was trained and evaluated on a small dataset of 85 participants. The reported held-out test results were obtained from 17 participants and should be interpreted cautiously.
The application should not be used for:
Clinical diagnosis
Treatment decisions
Mental-health screening without professional supervision
Evaluation of an individual's medical condition
Any clinical use would require larger datasets, independent external validation, clinical oversight, privacy protection, fairness assessment, and appropriate regulatory review.
